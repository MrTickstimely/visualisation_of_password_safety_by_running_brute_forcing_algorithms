This branch contains a random password checking algorithm and multiple brute force checking algorithms, they work from 4 digit numerical sequences to 6 digit alphanumerical sequences.
This project means no harm to anyone in any way, its a visualisation of how exhaustive brute forcing becomes when a large dataset is involved.
The time complexity of these algorithms are O(N^x) where x is the number of digits of the password. with a 4 digit alphanumerical sequence it can check up to a total of 1500625 combinations.
moreover, in a 6 digit alphanumerical sequence it can check upto 1838265625 combinations.
